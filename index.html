What is a network?

A network is two or more devices connected so they can share data and resources. At home, your phone, laptop and printer may all share one internet connection. In an office, hundreds of computers may share files, printers and email.

Networks give us three main benefits:

  • Sharing files and information
  • Sharing hardware such as printers and internet access
  • Communicating through email, calls and messaging
Every device on a network needs an address so that data knows where to go.

What each device does

Router
Connects your network to other networks, such as the internet, and directs data between them.
Switch
Connects devices inside one network and sends data only to the device that needs it.
Access point
Lets wireless devices join a wired network.
Network cable
Carries data between devices. Ethernet cables use a connector called RJ45.

How data travels: the OSI model

The OSI model describes the journey of data in seven layers. Data starts at layer 7 on the sender's computer, moves down to layer 1, travels across the cable, then moves back up on the receiver's computer.

  1. Application: programs such as web browsers and email
  2. Presentation: data format and encryption
  3. Session: starts, manages and ends connections
  4. Transport: splits data into pieces and checks delivery (TCP, UDP)
  5. Network: addresses and routing (IP)
  6. Data link: moves data between devices on one network (MAC addresses)
  7. Physical: cables, signals and ports

Basic troubleshooting

When someone says "I have no internet", work from the simple to the complex.

Steps to follow

  1. Check that the cable is plugged in, or that Wi-Fi is switched on.
  2. Restart the computer and check other devices on the same network.
  3. Restart the router or switch if several devices are affected.
  4. Run the commands in the table below to find where the problem is.
  5. If nothing works, report it to the network administrator or internet provider.

Frequently asked questions

What is an IP address?

A number that identifies a device on a network, for example 192.168.1.10.

What is the difference between a hub and a switch?

A hub sends data to every device. A switch sends it only to the device that needs it, which is faster and safer.

What is DHCP?

A service that gives IP addresses to devices automatically when they join a network.
